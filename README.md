# HONAC Controller

Deze Nederlandse stijl honac controller is ontworpen voor de game FiveM met specifieke keybinds aan de server [NLPDFR](https://nlpdfr.nl). Het biedt een realistische HONAC UI op je telefoon of mobiele apparaat die de ELS op je spel beheert. Bedoeld voor een realistischere ervaring.

## Installatie

Om dit programma te installeren download je de nieuwste release of de source code.

- Pak het ZIP-bestand uit en dubbelklik het `start.bat` bestand.
- Het programma installeert alle nodige tools & het start zichzelf
- In de commandline komt een URL te staan, die je op je telefoon kan openen. Zorg wel dat je op het zelfde netwerk zit

- Sluit de commandline niet af, dan stopt het programma. Mogelijk zijn beheerdersrechten nodig om de keybinds te laten functioneren

## Keybinds aanpassen

Speel je op een andere server of gebruik je andere keybinds dan de standaard? Pas deze aan in het `app.py` bestand.
